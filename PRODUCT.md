# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Stack

Static HTML/CSS/JS (no build step), deployed to GitHub Pages. Delegated: plain static files because GitHub Pages serves them directly and the project is a class assignment.

## Users

8th-grade students (grade 8A, INSTICALDAS, ages ~13–14) and their Informática teacher, Juan Carlos Isaza, who grades the page; plus any curious visitor who has heard of CrossFit but doesn't really know what it is. They arrive from a shared GitHub Pages link, usually on a phone or laptop. Author: María José Puentes Ballesteros (credited in the footer).

## Product Purpose

An informative landing page about CrossFit as a sport/training method (not a specific gym). Success: a visitor leaves understanding what CrossFit is, what a WOD is, the core movement families, how a class works, and that it scales to any level.

## Positioning

Explains CrossFit through its own native language: the WOD whiteboard, the scaling of the same workout for every level, and the vocabulary (AMRAP, EMOM, For Time, RX, box).

## Capabilities and Constraints

- Spanish-language content. Terminology rule: use Spanish everywhere (Escalado, Por tiempo, Cargada…); English CrossFit jargon appears only in the glossary, except names with no Spanish equivalent (WOD, RX, box, thruster), which are defined where first used.
- Single page, informative; primary action is understanding, secondary is "try a class at a box near you" (link to the official affiliate finder).
- Must work on GitHub Pages (relative paths, no server).

## Brand Commitments

None. CrossFit® is a registered trademark of CrossFit, LLC: the page must not use its logo or imitate the official site; it is an independent educational page.

## Evidence on Hand

No photos, testimonials or statistics provided. Do not invent testimonials or figures. Benchmark workouts ("Fran", "Murph", "Cindy") are public, well-known facts and can be cited.

## Product Principles

1. Teach by showing the real artifacts (a WOD, a scale), not by abstract claims.
2. Any level can start: scaling is the core message.
3. Honest and independent: no fake proof.
